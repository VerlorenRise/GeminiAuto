# Протокол параллельного выполнения задач с субагентами

Используй этот регламент при планировании и выполнении любых задач с привлечением субагентов:

1. **Сначала контракт**: Перед запуском субагентов самостоятельно определи структуру проекта, точные имена классов и сигнатуры методов, которыми они будут обмениваться.
2. **Жесткая изоляция файлов**: Запускай субагентов параллельно, но закрепляй за каждым строго отдельные файлы (1 файл = 1 агент). Двум субагентам запрещено одновременно редактировать один и тот же файл.
3. **Зоны ответственности**: Используй субагентов для параллельного поиска зависимостей, генерации конфигов (pom.xml, plugin.yml, config.yml и др.) и написания независимых классов по утвержденным сигнатурам.
4. **Финальная сборка**: Когда субагенты завершат работу, самостоятельно проверь импорты, свяжи классы в главном файле и выполни тестовую сборку.
