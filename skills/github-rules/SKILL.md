# Правила работы с GitHub и Git

1. **Строгая приватность 100%**:
   - Все репозитории и всё, что находится внутри них (ветки, теги, коммиты, PR), ОБЯЗАНЫ быть приватными (Private).
   - Публичные репозитории создавать строго запрещено.
2. **Приватная ветка проекта**:
   - Для каждого проекта создаётся отдельная рабочая ветка с названием проекта. Разработка ведётся в ней.
3. **Автоматическое версионирование коммитов от v0.0.1 до v9.9.9**:
   - Формат коммита: `vX.Y.Z: <Краткое понятное описание сделанного>`.
   - Нумерация строго возрастает от `v0.0.1` до `v9.9.9`. Патч инкрементируется на каждый завершённый шаг, минор — при завершении модуля.
   - Коммиты создаются после любых завершенных изменений и пушатся в проектную ветку.
4. **Режим автономности для /agent**:
   - В режиме скилла `/agent` агент имеет 100% автономность: создание проектной ветки, версионированные коммиты и пуш в приватный репозиторий выполняются автоматически без запросов подтверждения.
   - В ручном режиме диалога создание новых репозиториев на GitHub или удаление данных согласуются с пользователем.
